UsuarioDetails

br.edu.ifsp.associacaogaia.security
Adaptador que implementa a interface UserDetails do Spring Security envolvendo uma entidade Usuario, permitindo que o usuário da aplicação seja utilizado diretamente pelo mecanismo de autenticação/autorização do Spring Security. <p> É esta classe que expõe o usuário autenticado atrás de authentication.principal nas expressões @PreAuthorize usadas nos controllers (ex.: authentication.principal.usuario.idUsuario). <p> A conversão do br.edu.ifsp.associacaogaia.model.TipoUsuario do usuário para uma GrantedAuthority segue a convenção do Spring Security de prefixar o papel com "ROLE_" (ex.: tipo ADMINISTRADOR vira a autoridade ROLE_ADMINISTRADOR, o que permite o uso de hasRole('ADMINISTRADOR') nas regras de segurança).

Método
public Usuario getUsuario()
Obtém a entidade de usuário encapsulada por este adaptador. <p> Usado diretamente nas expressões @PreAuthorize dos controllers para acessar dados do usuário autenticado (ex.: authentication.principal.usuario.idUsuario).
Retorno: a entidade Usuario encapsulada.
Método
public Collection<? extends GrantedAuthority> getAuthorities()
Obtém as autoridades (papéis) concedidas ao usuário, derivadas do seu br.edu.ifsp.associacaogaia.model.TipoUsuario.
Retorno: uma lista contendo uma única GrantedAuthority no formato "ROLE_" + tipoUsuario (ex.: ROLE_VISITANTE, ROLE_ARTESAO ou ROLE_ADMINISTRADOR).
Método
public String getPassword()
Obtém a senha (já codificada) do usuário, usada pelo Spring Security para fins de autenticação por usuário/senha.
Retorno: a senha codificada (hash) do usuário.
Método
public String getUsername()
Obtém o nome de usuário (username) usado pelo Spring Security, que nesta aplicação corresponde ao e-mail do usuário.
Retorno: o e-mail do usuário.
Método
public boolean isAccountNonExpired()
Indica se a conta do usuário não está expirada.
Retorno: sempre true nesta aplicação, pois não há controle de expiração de conta implementado.
Método
public boolean isAccountNonLocked()
Indica se a conta do usuário não está bloqueada.
Retorno: sempre true nesta aplicação, pois não há controle de bloqueio de conta implementado.
Método
public boolean isCredentialsNonExpired()
Indica se as credenciais do usuário não estão expiradas.
Retorno: sempre true nesta aplicação, pois não há controle de expiração de credenciais implementado.
Método
public boolean isEnabled()
Indica se o usuário está habilitado.
Retorno: sempre true nesta aplicação, pois não há controle de habilitação/desabilitação de conta implementado.
