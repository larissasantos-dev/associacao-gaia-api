UsuarioService

br.edu.ifsp.associacaogaia.service
Serviço que concentra as regras de negócio relacionadas a usuários: listagem, busca, cadastro e autenticação (login). <p> Regras de autorização (quem pode chamar cada operação) não são tratadas aqui — são aplicadas na camada de controller/segurança (SecurityConfig e anotações @PreAuthorize em UsuarioController). Este serviço assume que a chamada já foi autorizada.

Construtor
public UsuarioService(UsuarioRepository usuarioRepository, PasswordEncoder passwordEncoder)
Cria o serviço injetando o repositório de usuários e o codificador de senhas.
Parâmetros:
  • usuarioRepository — repositório usado para persistir e consultar usuários.
  • passwordEncoder — codificador usado para codificar e verificar senhas.
Método
public List<Usuario> listarUsuarios()
Lista todos os usuários cadastrados no sistema. <p> O controle de que apenas um ADMINISTRADOR pode chamar esta operação é feito fora deste serviço (em SecurityConfig).
Retorno: lista com todos os Usuario cadastrados (lista vazia caso não haja nenhum).
Método
public Optional<Usuario> buscarUsuario(Long id)
Busca um usuário pelo seu identificador.
Parâmetros:
  • id — identificador do usuário a ser buscado.
Retorno: um Optional contendo o Usuario encontrado, ou um Optional vazio caso não exista usuário com o id informado.
Método
public Optional<Usuario> buscarUsuarioPorEmail(String email)
Busca um usuário pelo seu e-mail.
Parâmetros:
  • email — e-mail do usuário a ser buscado.
Retorno: um Optional contendo o Usuario encontrado, ou um Optional vazio caso não exista usuário com o email informado.
Método
public Usuario cadastrarUsuario(UsuarioCadastroDTO dados)
Cadastra um novo usuário a partir dos dados informados. <p> Verifica previamente se já existe um usuário com o mesmo e-mail, codifica a senha recebida antes de persistir e cria o usuário sempre com o tipo TipoUsuario#VISITANTE — este é o único ponto do código onde esse valor padrão é definido.
Parâmetros:
  • dados — dados de cadastro do usuário (nome, e-mail, senha e telefone).
Retorno: o Usuario recém-criado e persistido, já com o identificador gerado pelo banco de dados.
Exceções:
  • EmailJaCadastradoException — se já existir um usuário cadastrado com o mesmo e-mail informado em dados.
Método
public Usuario realizarLogin(LoginDTO dados)
Autentica um usuário a partir do e-mail e senha informados. <p> Busca o usuário pelo e-mail e, se encontrado, verifica se a senha informada corresponde à senha codificada armazenada, usando PasswordEncoder#matches(CharSequence,. Não gera nem retorna o token JWT — essa responsabilidade é do UsuarioController, que utiliza TokenService separadamente após este método retornar com sucesso.
Parâmetros:
  • dados — credenciais de login (e-mail e senha em texto puro).
Retorno: o Usuario autenticado, caso o e-mail exista e a senha informada seja válida.
Exceções:
  • CredenciaisInvalidasException — se não existir usuário cadastrado com o e-mail informado, ou se a senha informada não corresponder à senha cadastrada.
