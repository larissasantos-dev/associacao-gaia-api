UsuarioCadastroDTO

br.edu.ifsp.associacaogaia.dto
DTO (Data Transfer Object) usado para receber os dados informados pelo usuário na requisição de cadastro (POST /api/usuarios). <p> Note que as anotações de validação Bean Validation estão nos métodos getter (e não nos campos), então é a leitura dos dados (ex.: durante a validação do corpo da requisição) que é validada. <p> Não possui campo de tipo de usuário: todo usuário cadastrado por este DTO é criado como VISITANTE pela camada de serviço.

Construtor padrão sem argumentos, exigido para a desserialização do corpo da requisição (JSON) em uma instância de UsuarioCadastroDTO.
Método
public String getNome()
Obtém o nome informado para cadastro.
Retorno: o nome do usuário. Não pode ser nulo/vazio (@NotBlank).
Método
public String getEmail()
Obtém o e-mail informado para cadastro.
Retorno: o e-mail do usuário. Não pode ser nulo/vazio e deve estar em formato de e-mail válido (@NotBlank, @Email).
Método
public String getSenha()
Obtém a senha informada para cadastro.
Retorno: a senha em texto puro informada pelo usuário. Não pode ser nula/vazia (@NotBlank).
Método
public String getTelefone()
Obtém o telefone informado para cadastro.
Retorno: o telefone do usuário. Não pode ser nulo/vazio (@NotBlank).
