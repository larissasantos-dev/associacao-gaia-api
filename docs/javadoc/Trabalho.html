Trabalho

br.edu.ifsp.associacaogaia.model
Entidade JPA que representa um trabalho/peça publicado por um Artesao em seu perfil, mapeada para a tabela trabalho no banco de dados. <p> <b>Observação:</b> assim como Artesao, no código atual do projeto não há nenhum Service/Controller que crie ou gerencie instâncias desta entidade. Diferente de Usuario#Usuario, que preenche sua data de criação automaticamente no construtor, esta classe não possui nenhuma lógica que preencha dataPublicacao automaticamente — apesar de a coluna correspondente ser obrigatória (nullable = false) no banco, cabe a quem futuramente criar/usar esta entidade garantir que o valor seja definido via setDataPublicacao.
