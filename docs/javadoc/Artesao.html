Artesao

br.edu.ifsp.associacaogaia.model
Entidade JPA que representa o perfil público de um artesão, mapeada para a tabela artesao no banco de dados. <p> Um Artesao sempre está vinculado a um Usuario (relação um-para-um, obrigatória e única) e reúne as informações exibidas no perfil público do artesão (biografia, redes sociais, cidade, etc.), além dos Trabalhos publicados por ele. <p> <b>Observação:</b> no código atual do projeto não há nenhum Service/Controller que crie ou gerencie instâncias desta entidade — ela existe como modelagem de domínio para a futura funcionalidade de promoção de VISITANTE para ARTESAO (mediante solicitação aprovada por um ADMINISTRADOR), ainda não implementada.

Atributo
private Long idArtesao
Identificador único do perfil de artesão, gerado automaticamente pelo banco de dados.
Atributo
private Usuario usuario
Usuário ao qual este perfil de artesão pertence. Obrigatório e único (um usuário tem no máximo um perfil de artesão).
Atributo
private String nomeExibicao
Nome de exibição do artesão no perfil público. Obrigatório, com até 150 caracteres.
Atributo
private String tituloCurto
Título curto/subtítulo exibido junto ao nome no perfil público. Opcional, com até 200 caracteres.
Atributo
private String biografia
Biografia completa do artesão, exibida no perfil público. Opcional, armazenada como texto longo (LOB).
Atributo
private String lead
Texto de destaque/chamada ("lead") exibido no perfil público. Opcional, armazenado como texto longo (LOB).
Atributo
private String cidade
Cidade onde o artesão está localizado/atua. Opcional, com até 100 caracteres.
Atributo
private String membroDesde
Texto livre indicando desde quando o artesão é membro da associação. Opcional, com até 50 caracteres.
Atributo
private String locaisAtendimento
Descrição dos locais onde o artesão atende. Opcional, com até 255 caracteres.
Atributo
private String avatarUrl
URL da imagem de avatar/perfil do artesão. Opcional, com até 255 caracteres.
Atributo
private String instagram
Nome de usuário/handle do artesão no Instagram. Opcional, com até 100 caracteres.
Atributo
private String whatsappUrl
URL de contato do artesão via WhatsApp. Opcional, com até 255 caracteres.
Atributo
private String facebookUrl
URL do perfil do artesão no Facebook. Opcional, com até 255 caracteres.
Atributo
private List<Trabalho> trabalhos
Lista de trabalhos publicados por este artesão. Relação um-para-muitos com Trabalho, mapeada pelo lado inverso em Trabalho#getArtesao(); operações de persistência são propagadas em cascata (CascadeType.ALL) e trabalhos removidos desta lista são automaticamente excluídos do banco (orphanRemoval = true).
