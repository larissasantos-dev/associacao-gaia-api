Construtor
public Usuario(String nome, String email, String senha, String telefone, TipoUsuario tipoUsuario)
Cria um novo usuário com os dados informados. <p> A dataCadastro é preenchida automaticamente com o instante atual (LocalDateTime#now()) no momento da construção.
Parâmetros:
  • nome — nome completo do usuário.
  • email — e-mail do usuário (deve ser único no sistema).
  • senha — senha já codificada (hash) do usuário.
  • telefone — telefone de contato do usuário.
  • tipoUsuario — tipo/papel inicial do usuário no sistema.

public void setTipoUsuario(TipoUsuario tipoUsuario)
Define o tipo/papel do usuário no sistema. <p> Usado, por exemplo, para promover um usuário de VISITANTE para ARTESAO (fluxo de solicitação/aprovação ainda não implementado em outras classes do projeto) ou para conceder o papel ADMINISTRADOR.
