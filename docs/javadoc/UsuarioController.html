UsuarioController

br.edu.ifsp.associacaogaia.controller
Controller REST responsável pelos endpoints relacionados a usuários: cadastro, autenticação (login) e consulta de usuários. <p> Todos os endpoints deste controller são expostos sob o prefixo /api/usuarios. As regras de quem pode acessar cada endpoint são aplicadas em duas camadas: <ul> <li>a nível de rota/URL, em SecurityConfig (ex.: cadastro e login são públicos; listagem completa exige papel ADMINISTRADOR);</li> <li>a nível de método, via @PreAuthorize, para regras que dependem do usuário autenticado (ex.: só o próprio usuário ou um administrador podem buscar por id/e-mail).</li> </ul> Todo usuário cadastrado por este controller nasce com o tipo VISITANTE; a promoção a ARTESAO depende de um fluxo de solicitação/aprovação por um ADMINISTRADOR ainda não implementado neste controller.
Membros documentados
Construtor
public UsuarioController(UsuarioService usuarioService, TokenService tokenService)
Cria o controller injetando os serviços de domínio de usuário e de geração/validação de token JWT.
Parâmetros:
  • usuarioService — serviço responsável pelas regras de negócio de cadastro, busca e autenticação de usuários.
  • tokenService — serviço responsável por gerar o token JWT entregue ao usuário após um login bem-sucedido.
Método
public List<UsuarioResponseDTO> listarUsuario()
Lista todos os usuários cadastrados no sistema. <p> O acesso a este endpoint (GET /api/usuarios) é restrito a usuários com papel ADMINISTRADOR; essa restrição é aplicada em SecurityConfig (a nível de rota), e não por uma anotação @PreAuthorize neste método.
Retorno: lista de UsuarioResponseDTO representando todos os usuários cadastrados (lista vazia caso não haja nenhum).
Método
public UsuarioResponseDTO cadastrarUsuario(@Valid @RequestBody UsuarioCadastroDTO dados)
Cadastra um novo usuário no sistema. <p> Endpoint público (não exige autenticação). Todo usuário criado por este método recebe automaticamente o tipo VISITANTE (a definição do tipo é feita em UsuarioService, não neste controller). A senha recebida é validada e, antes de ser persistida, codificada pelo serviço de domínio.
Parâmetros:
  • dados — dados de cadastro do usuário (nome, e-mail, senha e telefone), validados via Bean Validation (@Valid) antes de chegar ao método.
Retorno: UsuarioResponseDTO representando o usuário recém-criado.
Exceções:
  • br.edu.ifsp.associacaogaia.exception.EmailJaCadastradoException — se já existir um usuário cadastrado com o mesmo e-mail (lançada pelo serviço de domínio e tratada globalmente, resultando em resposta 409 Conflict).
Método
public LoginResponseDTO realizarLogin(@Valid @RequestBody LoginDTO dados)
Autentica um usuário a partir de e-mail e senha, retornando um token JWT para uso nas requisições subsequentes. <p> Endpoint público (não exige autenticação prévia).
Parâmetros:
  • dados — credenciais de login (e-mail e senha), validadas via Bean Validation (@Valid) antes de chegar ao método.
Retorno: LoginResponseDTO contendo o token JWT gerado e os dados do usuário autenticado.
Exceções:
  • br.edu.ifsp.associacaogaia.exception.CredenciaisInvalidasException — se não existir usuário com o e-mail informado ou se a senha informada não corresponder à senha cadastrada (lançada pelo serviço de domínio e tratada globalmente, resultando em resposta 401 Unauthorized).
