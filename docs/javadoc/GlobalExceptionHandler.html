GlobalExceptionHandler

br.edu.ifsp.associacaogaia.exception
Manipulador global de exceções da API. <p> Centraliza a conversão das exceções de negócio lançadas pelos serviços (ex.: EmailJaCadastradoException, CredenciaisInvalidasException) em respostas HTTP apropriadas, evitando que cada controller precise tratá-las individualmente.
Membros documentados
Método
public String tratarEmailJaCadastrado(EmailJaCadastradoException exception)
Trata o caso de tentativa de cadastro com e-mail já existente.
Parâmetros:
  • exception — exceção capturada, lançada ao tentar cadastrar um usuário com e-mail já registrado.
Retorno: a mensagem da exceção, usada como corpo da resposta HTTP 409 Conflict.
Método
public String tratarCredenciaisInvalidas(CredenciaisInvalidasException exception)
Trata o caso de credenciais inválidas em uma tentativa de login.
Parâmetros:
  • exception — exceção capturada, lançada quando o e-mail não existe ou a senha informada está incorreta.
Retorno: a mensagem da exceção, usada como corpo da resposta HTTP 401 Unauthorized.
