TipoUsuario

br.edu.ifsp.associacaogaia.model
Enumera os papéis (tipos) que um Usuario pode assumir no sistema, usados para controle de acesso. <p> Todo usuário é cadastrado como VISITANTE por padrão. A promoção de VISITANTE para ARTESAO depende de um fluxo de solicitação avaliada e aprovada por um ADMINISTRADOR, que ainda não está implementado no código atual desta aplicação.
Membros documentados
Valor do enum
VISITANTE
Usuário recém-cadastrado, com acesso básico; é o tipo padrão de todo novo cadastro.
Valor do enum
ARTESAO
Usuário promovido a artesão, após aprovação de um administrador (fluxo de promoção ainda não implementado).
Valor do enum
ADMINISTRADOR
Usuário com privilégios administrativos, com acesso irrestrito às operações da API.
