Associação Gaia API

Backend Spring Boot / Java / MySQL — sistema de associação de artesãos (cadastro, login via JWT e controle de acesso por tipo de usuário).

Este site foi gerado a partir dos comentários Javadoc já presentes no código-fonte. Não é a saída da ferramenta oficial javadoc do JDK (que exigiria resolver todas as dependências do projeto — Spring, JPA, JJWT — via Maven Central, indisponível neste ambiente); é um gerador próprio que lê os mesmos comentários e monta esta navegação em HTML.
